# Poprawiony pakiet — Święty Kościół Katolicki

Pakiet przygotowany jako korekta poprzedniej wersji. Nie przebudowuje stylistyki strony; bazuje na istniejącym układzie plików i dodaje tylko elementy dotyczące św. Cypriana, biblioteki Prawosławie oraz kalendarza świętych.

## Elementy
- `index.html` — istniejący wygląd zachowany; św. Cyprian pozostaje w sekcji Najnowsze, a Prawosławie prowadzi do biblioteki.
- `prawoslawie.html` — biblioteka: „Prymat biskupa Rzymu w sferze jurysdykcji”.
- `article-cyprian-rzym.html` — artykuł o św. Cyprianie.
- `calendar-1954.js` — mechanizm sekcji „Święci dnia dzisiejszego”.
- `assets/cyprian-rzym.png` — grafika artykułu.

Uwaga: ten pakiet jest przygotowany na podstawie plików dostępnych w poprzednim pakiecie. Aby zagwarantować piksel-w-piksel zachowanie aktualnej wersji opublikowanej strony, potrzebny jest aktualny eksport/repozytorium strony.
