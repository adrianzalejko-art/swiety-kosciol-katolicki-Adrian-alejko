# Pakiet zmian — Święty Kościół Katolicki

Pakiet zawiera wyłącznie zakres zmian ustalony dla artykułu o św. Cyprianie i sekcji świętych.

## Zmienione elementy

- `article-cyprian-rzym.html` — nowy artykuł.
- `assets/cyprian-rzym.png` — grafika artykułu.
- `index.html` — dodano artykuł do „Najnowszych” oraz sekcję „Święci dnia dzisiejszego”.
- `calendar-1954.js` — bezserwerowa obsługa daty i kalendarza w stylu stanu z 1954 r.; sekcja zmienia się automatycznie każdego dnia według daty urządzenia.
- `zarzuty.html` — rozbudowano kartę „Prawosławie” o bibliotekę „Prymat biskupa Rzymu w sferze jurysdykcji” i dodano tam artykuł Cypriana.

## Ważne

Skrypt działa po stronie przeglądarki, więc nie wymaga codziennego ręcznego publikowania nowej wersji strony. GitHub Pages może publikować zwykłe pliki HTML/CSS/JS z repozytorium. Po wypchnięciu zmian publikacja może potrwać kilka minut.

Kalendarz korzysta z układu General Roman Calendar as in 1954, czyli stanu sprzed reformy 1955. Dane stałe obejmują najważniejsze wpisy kalendarzowe, a główne święta ruchome są wyliczane automatycznie dla aktualnego roku. Przed wdrożeniem produkcyjnym pełną bazę wszystkich kommemoracji można rozszerzyć bez zmiany mechanizmu strony.
